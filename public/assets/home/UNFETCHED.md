# Home page — asset notes

No binary assets were downloaded for this page. Every icon in the Figma design
(node `2:2`) is a simple monochrome line glyph exported behind expiring
`api/mcp/asset` URLs. Per the project conventions (common glyphs may be rendered
with `lucide-react`), these were substituted with matching lucide icons instead
of downloading short-lived SVGs:

- Hero / CTA / link arrows → `ArrowRight`
- "What's covered" list checks (Our Solution) → `Check`
- Why ScaleOut cards → `MapPin`, `ShieldCheck`, `Code2`
- Our Services cards → `Code2`, `ShieldCheck`, `Building2`, `Users`
- Comparison table status → `Check` (Yes), `Minus` (Partial), `X` (No)
- FAQ row affordance → `ChevronDown`
